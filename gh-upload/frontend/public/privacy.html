2. Como usamos os dados

Apenas para enviar alertas climáticos. Não usamos para marketing, não vendemos, não partilhamos.

3. Os seus direitos

  • ✅ Aceder aos dados
  • ✅ Rectificar dados incorrectos
  • ✅ Apagar (unsubscribe ou email)
  • ✅ Portabilidade (exportar)
  • ✅ Oposição ao processamento

Para exercer: eden.mucache@gmail.com

4. Segurança

  • TLS/HTTPS em todas as comunicações
  • Tokens HMAC-SHA256 com timing-safe compare
  • Headers de segurança (CSP, X-Frame-Options, etc.)
  • Sem armazenamento de passwords (não há login)
  • RFC 8058 one-click unsubscribe

5. Retenção de dados

  • Subscritor activo: até cancelar
  • Logs de envio: 100 últimos (~7 dias)
  • Alertas em cache: até 3h (depois expiram)
